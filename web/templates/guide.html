GUÍA DE MÓDULOS

Qué pregunta responde cada herramienta

Negro no intenta adivinar vulnerabilidades. Cada módulo responde una pregunta concreta sobre evidencia observada en Burp.

BUSCAR

¿Dónde aparece esto?

Entrada universal. Busca texto, valores parciales, parámetros, headers, cookies, request/response, Signals, notas e investigaciones.

4101 · AIza · ownerId · response:email

Úsalo cuando ya tienes una pista y quieres encontrar todas sus apariciones.

FOLLOW VALUE

¿Dónde reaparece exactamente este valor?

Sigue un valor concreto por request, response, path o distintos nombres de campo.

diego@... → login → /me → /profile

No analiza todo el exchange; sigue sólo el valor seleccionado.

FIND RELATED EXCHANGE

¿Qué otros exchanges parecen conectados con este?

Toma todos los valores útiles de request + response y busca otros exchanges con coincidencias exactas. Descarta ruido común.

login ↔ /me por email + user id + phone

Una relación es contexto, no prueba de “mismo objeto” ni vulnerabilidad.

SMART COMPARE

¿Qué coincide y qué cambia entre A y B?

Primero muestra valores exactos compartidos, incluso bajo nombres/rutas distintas; después muestra diferencias estructuradas.

userId=102 ↔ memberId=102

“Posible alias” significa misma evidencia de valor, no equivalencia semántica confirmada.

IDENTIDADES

¿Quién hizo este tráfico?

Separa Identity, Auth Material y Resolver. Una cookie/token puede rotar sin crear otra identidad.

ANA → /me.id=101 → sesión nueva → misma Identity

Resolvers identifican al actor; ownerId/orderId describen objetos y no deben resolver al actor.

FLOWS

¿Qué historia de negocio forman varios exchanges?

Agrupa pasos observados, conserva su orden, identidad y estados de negocio. Puedes comparar dos recorridos.

login → cart → checkout → payment → order

Úsalo para lógica de negocio, secuencias, estados y diferencias entre cuentas o caminos.
